# 🏥 MediMind AI: Multi-Modal Disease Prediction & Clinical Risk Analytics

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![Scikit-Learn](https://img.shields.io/badge/Scikit--Learn-1.3%2B-orange.svg)](https://scikit-learn.org/)

An end-to-end Machine Learning pipeline and Clinical Decision Support System (CDSS) designed for early-stage disease prediction and patient risk categorization.

---

## 🔬 Key Features

* **Multi-Disease Inference Engine:** Real-time risk estimation for Cardiovascular Disease and Diabetes.
* **Ensemble ML Pipeline:** Leverages Random Forest Classifiers for high-accuracy predictions.
* **Feature Importance Analytics:** Identifies key health biomarkers driving patient risk.
* **Dynamic Patient Profiling:** Classifies patients into Low, Moderate, or High-risk tiers.

---

## 🛠️ Tech Stack

* **Language:** Python 3.9+
* **Libraries:** Scikit-Learn, NumPy, Pandas
